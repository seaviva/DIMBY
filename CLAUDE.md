# Claude Code Project Guide

This repository is intentionally minimal while we gather requirements and plan the build.

## How to work in this repo
- Prefer small, reviewable changes.
- Keep docs in Markdown under the repo root for now.
- Record decisions in `docs/decisions.md` once we start making architectural choices.
- Keep all data sources, licenses, and attribution notes in `docs/data-sources.md`.

## Project intent
A web experience featuring an interactive heat map of NYC real estate valuation data.

## Workflow expectations
- Start from the requirements in `docs/product-brief.md`.
- Track milestones and acceptance criteria in `docs/roadmap.md`.
- Capture architecture choices (stack, data pipeline, hosting) in `docs/architecture.md`.

## What Claude should ask before coding
- Confirm target users and primary use cases.
- Confirm data sources and licensing constraints.
- Confirm desired interactivity and performance targets.
- Confirm deployment target and hosting constraints.
